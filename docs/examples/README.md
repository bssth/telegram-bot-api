# Examples

With a better understanding of how the library works, let's look at examples showing off Telegram's features:

- [Command Handling](./command-handling.md) — parse and respond to bot commands with replies and link preview controls.
- [Keyboard](./keyboard.md) — custom reply keyboards.
- [Inline Keyboard](./inline-keyboard.md) — inline buttons and callback queries.
- [Rich Messages](./rich-messages.md) — structured blocks and Markdown rich messages with embedded media.
- [Ephemeral Messages](./ephemeral-messages.md) — targeted messages visible only to a specific user.
- [Poll Media](./poll-media.md) — polls with photos, links, and media attached to options, descriptions, or quiz explanations.
- [Business Connections](./business-connections.md) — connecting to Telegram Business accounts and handling business messages.
